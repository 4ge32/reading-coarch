# Share extraction test fixtures

The HTML articles are original project test material. `JSDOMParser.js` is an
unchanged test-only file from `@mozilla/readability` 0.6.0, covered by its retained
MPL-2.0 source header and the complete `MPL-2.0.txt` license here. It is not bundled
with the iOS app. The npm package integrity and source hashes are verified in
`scripts/test-share.mjs`.

The app's separate vendored `Readability.js` is Apache-2.0, as stated by its
upstream source header; its notices live under the extension's ThirdParty folder.
